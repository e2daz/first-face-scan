# First Face Scan

This project is a Python face detection program for a practica task.

## Goal
Build a Python program that detects faces in images.

The program should work with either:
- a still image file, or
- a webcam stream in real time.

## Requirements
- Detect faces.
- Visibly mark detections (for example, with bounding boxes).
- Accept input from an image file or the webcam.
- Include brief run instructions.
- You may use any suitable library (for example, OpenCV or MediaPipe).

## How to Run
1. Install dependencies (example):
   ```bash
   pip install opencv-python
   ```
2. Run with a still image:
   ```bash
   python main.py --image path/to/image.jpg
   ```
3. Run with webcam:
   ```bash
   python main.py --webcam
   ```

> Note: If your script uses different filenames or arguments, adjust the commands accordingly.
